CSS-Selektoren

Basis & Attribute

Universal (*)

Wählt alles.

* { margin: 0; }
Klasse (.)

Wählt Klassen.

.btn { color: red; }
ID (#)

Einzigartig.

#nav { top: 0; }
Attribut ([])

Nach HTML-Werten.

[type="text"] { }

Kombinatoren

Nachfahre ( )

Alle Ebenen tiefer.

div p { }
Kind (>)

Nur direkte Ebene.

ul > li { }
Nachbar (+)

Direkt folgendes Element.

h1 + p { }
Geschwister (~)

Alle folgenden gleichen Typs.

h1 ~ p { }

Vergleich

Kombinatoren (Struktur) Klassen (Komponenten)
Sauberes HTML (weniger Markup) Struktur-unabhängig (flexibel)
Automatisch für neue Elemente Hohe Spezifität & Eindeutigkeit

Schätzung: Nutzung ca. 70% Klassen / 30% Kombinatoren.
